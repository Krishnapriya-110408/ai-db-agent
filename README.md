##  Project Overview

AI Database Chat Agent is an AI-powered application that allows users to interact with an e-commerce database using natural language.

Instead of manually writing complex SQL queries, users can simply ask questions in normal English. The AI agent understands the question, analyzes the database, and provides useful results, visualizations, and AI-generated insights.

##  How the AI Agent Works

The agent follows these steps:

1. User enters a question in natural language.
2. The AI agent understands the user's request.
3. The request is converted into a suitable SQL query.
4. The SQL query is executed on the e-commerce database.
5. The retrieved data is analyzed.
6. The result is displayed to the user.
7. Based on the request, the agent can generate charts, diagrams, and AI insights.

### Workflow

**User Question → AI Agent → SQL Query → Database → Data Analysis → Result / Visualization**
